# Glitched Together — Story Bible

Sep 30, 2026 · @buldak

## Overview

*Glitched Together* is a two-player online co-op adventure on Roblox where two ex-best friends get pulled into the unfinished game they made as kids and must fix it, and their friendship, to escape.

**Roblox listing name:** \[2 PLAYER\] Glitched Together 👾 (the tag tells players in search results it's a duo game; "CONTINUE?" stays as the in-story message and end-screen card).

| Item | Detail |
| --- | --- |
| Platform | Roblox (Luau) |
| Players | Exactly 2, online, one per character (no solo mode) |
| Genre | Story-driven co-op action-platformer, It Takes Two-style structure |
| Length target | 3 worlds + prologue and epilogue, about 1.5 to 2.5 hours |
| Core rule | Every puzzle needs both players; no section can be finished alone |
| Structure | Each world has its own look, its own ability pair, its own boss and one unlocked memory |

**Design rules for the whole game**

- Each world swaps the camera style and the ability pair, so the game never feels the same for long.
- The two abilities in a world are useless alone and powerful together.
- Story is told in short cutscenes (under 60 seconds) between gameplay, plus in-game dialogue while playing.
- All names, characters, art, music and items are original. Only the co-op structure is inspired by It Takes Two.

## Characters

Four characters carry the story: the two players, a helper NPC, and the villain.

**Kai (Player 1)**

- Male, age 19. Quiet, careful, holds grudges. Was the "idea person" who wrote the lore and drew the maps for *Starfall Kingdom*.
- Believes Miko abandoned him and the game.
- Plays the planner role: abilities that set things up (freeze, build, cast).
- In-game look: a hoodie avatar at first; becomes the **Fire Mage** in the castle.

**Miko (Player 2)**

- Female, age 19. Loud, impulsive, jokes to avoid serious talk. Was the "builder" who made the levels and tested everything.
- Believes Kai stopped caring and shut her out.
- Plays the action role: abilities that move and hit (dash, grapple, shield).
- In-game look: a jacket avatar at first; becomes the **Shield Knight** in the castle.

**Pip (helper NPC)**

- A small floating pixel sprite: the tutorial guide Kai and Miko coded as kids but never finished. Half its lines are placeholder text ("INSERT JOKE HERE").
- Explains mechanics, gives hints, and slowly pushes the two to talk to each other.
- Comic relief. Glitches more as The Glitch gets stronger.

**The Glitch (villain)**

- A corruption eating *Starfall Kingdom*, made of every unfinished file, deleted chat and unsent message.
- Appears as flickering static that takes a new boss form in each world.
- Speaks using twisted versions of things Kai and Miko said to each other during the fight that ended their friendship.
- Cannot be killed, only *completed* (see the final boss).

## Backstory

The falling-out was a misunderstanding on both sides, and the player learns the full truth only through the three memories.

**The friendship (age 11 to 15).** Kai and Miko were neighbors who spent every afternoon making a game together called *Starfall Kingdom*. It had three areas: a retro platformer start zone, a fantasy castle, and a "secret final level" they never finished. They promised to release it together on Kai's 16th birthday.

**The falling-out (age 15).** Miko's family had to move to another city suddenly. Miko was scared and embarrassed, so she kept putting off telling Kai.

- Miko finally wrote a long goodbye message and saved it inside the game as a hidden note, planning to show Kai at the launch. She never got the chance.
- Kai found out from someone else that Miko was leaving and felt betrayed. He skipped the launch day on purpose.
- Miko waited alone, thought Kai didn't care, and left without saying goodbye.
- Kai then deleted his copy of the project in anger. Miko stopped replying to messages.

Neither has spoken to the other in four years.

**What each believes vs. the truth**

| Who | What they believe | The truth |
| --- | --- | --- |
| Kai | Miko hid the move and left without caring | Miko was scared, and wrote a goodbye she hid in the game |
| Miko | Kai skipped launch day because he didn't care | Kai was hurt, and came to her house the next morning, but she had already left |

**The inciting event (present day).** On the night of Kai's 20th birthday, both receive the same message from an unknown sender: *"Your save file is still here. CONTINUE?"* Both click yes, separately, and are pulled into the game.

## Shared moveset and co-op systems

Both players always have the same base moves; only the world abilities differ.

**Base moves (all worlds except the top-down castle)**

| Move | Input (PC / mobile) | Notes |
| --- | --- | --- |
| Jump / double jump | Space / jump button | Double jump unlocked from the start |
| Dash | Shift / dash button | Short burst, works in air, 1 s cooldown |
| Ground pound | Ctrl in air / hold jump in air | Presses heavy buttons, breaks cracked floors |
| Interact | E / tap prompt | Levers, doors, carrying objects |
| World tool (use 1 / use 2) | Left click, right click / on-screen buttons | One tool per player, new tool each world |

**Co-op systems**

- **Respawn:** when a player dies, they turn into a small ghost and come back after a few seconds; mashing a button brings them back faster (It Takes Two). If both die, restart at the last checkpoint.
- **Checkpoints:** shared. Reaching one saves progress for both players.
- **Two-player gates:** doors and elevators only open when both players stand on their plates.
- **Partner marker:** an outline shows your partner through walls so you never lose each other.
- **Ping:** a key (Q) drops a marker for the partner; useful for players without voice chat.

## Prologue: The Title Screen

A 5 to 10 minute tutorial that teaches the base moves and makes clear the two refuse to talk.

**Story beats**

1. **Cutscene: "CONTINUE?"** Split view of both players in their own rooms, years apart, clicking the message. Both get sucked into their screens.
2. They land on a giant, broken version of the *Starfall Kingdom* title screen. Awkward silence. Miko jokes; Kai ignores her.
3. **Pip appears**, happy to see them: "PLAYER ONE! PLAYER TWO! You came back! ...Why are you standing so far apart?"
4. Pip explains the world is being eaten by The Glitch and the only way out is the exit at the end of the game. They must go together because the game was coded to need two players ("You wrote that rule! Line 42!").
5. Tutorial run across the menu: jumping over giant buttons, dashing across the "Options" slider, ground-pounding the "Load Game" button.
6. **First two-player gate:** a door that needs both on plates. Neither moves first. Pip: "This is going to be a long game."
7. **Cutscene:** The Glitch swallows the title screen behind them. They escape through the "New Game" door into World 1.

**Gameplay taught:** jump, double jump, dash, ground pound, interact, respawn (mash to come back faster), two-player plates, checkpoints.

**Tone goal:** funny on the surface, obviously tense underneath.

## World 1: Pixel Plains (retro platformer)

The first zone they ever built: a bright 8-bit platformer, now full of glitch holes, where the two are forced to cooperate for the first time and end on their first real argument.

**Look:** blocky pixel terrain, chunky clouds, coin blocks, chiptune music. Third-person camera, side-on in some sections.

**Ability pair**

| Player | Tool | Use 1 | Use 2 |
| --- | --- | --- | --- |
| Kai | **Pause Beam** | **Freeze:** locks a moving object in place for 4 s (platforms, crushers, falling blocks, enemies) | **Release:** unfreezes it early so it snaps back into motion |
| Miko | **Grapple Line** | **Swing:** latches onto grapple rings and frozen objects | **Pull:** yanks light objects (crates, levers, loose parts) toward her |

**How they combine:** Kai freezes a crusher mid-fall so Miko can run under it; Kai freezes falling blocks in mid-air so Miko can swing across a gap; Miko pulls a crate onto a switch while Kai holds a moving door frozen open.

**Level sections**

1. **1-1 Starter Meadow:** learn the abilities one at a time. Pip gives hints.
2. **1-2 Cloud Climb:** vertical climb on moving platforms. Kai freezes them in position; Miko grapples up and drops ropes for Kai.
3. **1-3 Coin Factory:** conveyors, crushers and timed doors. Heavier puzzles that need both abilities in sequence.

**Boss: The Crusher King.** A giant pixel king made of stacked blocks, infected by The Glitch.

- Phase 1: he slams his fists. Kai freezes a fist; Miko grapples onto it and ground-pounds the crystal on his wrist.
- Phase 2: the floor falls away. Kai freezes falling floor tiles in mid-air to stand on while Miko swings between them.
- Phase 3: the crown on his head is the weak point. Kai freezes him, Miko grapples up and pulls it off.

**Memory 1: "Level One" (unlocked after the boss)**

- Flashback, age 12: the two kids on Kai's bedroom floor, building this exact level. Miko draws a crown on the Crusher King and laughs.
- Miko: "When we finish it, we launch it together. No matter what." They pinky-promise.

**End-of-world scene:** back in the present, Kai says quietly, "You promised." Miko snaps back, "So did you." They walk into World 2 without speaking. Pip, nervously: "...Great teamwork, everyone!"

## World 2: Starfall Castle (top-down dungeon crawler)

The heart of *Starfall Kingdom*: the two become the fantasy classes they designed for themselves, Fire Mage and Shield Knight, and the world ends with Miko's side of the story coming out.

**Look:** dark stone halls, torches, banners, stained glass, orchestral-fantasy music. **Camera switches to top-down** (fixed overhead, following the midpoint between both players).

**Cutscene on entry:** stepping through the gate transforms them into their old characters. Miko laughs at Kai's wizard hat; Kai almost smiles, then stops himself.

**Ability kit (replaces base moves here; dash stays)**

| Player | Basic attack | Skill 1 | Skill 2 | Ultimate |
| --- | --- | --- | --- | --- |
| Kai, Fire Mage | Fireball (ranged) | **Flame Wall:** a line of fire that blocks a corridor and burns enemies passing through | **Ignite:** lights braziers, burns webs and wooden doors | **Meteor:** charged area blast |
| Miko, Shield Knight | Sword combo (melee) | **Shield Block:** blocks all damage from the front; **reflects fireballs** | **Shield Charge:** dashes forward, breaks walls, shoves enemies | **Rally:** shockwave that stuns everything nearby |

**How they combine:** Miko reflects Kai's fireballs off her shield to hit switches around corners; Kai lights torches so Miko can see floor traps in dark rooms; Miko shoves enemies into Kai's Flame Wall for double damage.

**Progression:** enemies drop XP orbs. Each player reaches level 2 and 3 in this world, and at each level picks one of two upgrades (for example: bigger Fireball or faster cast; longer Shield Block or wider Charge).

**Level sections**

1. **2-1 Castle Gates:** learn the classes; small enemy waves (glitched skeletons, slimes).
2. **2-2 Dark Library:** mostly dark rooms. Kai lights the path; Miko reflects fire to open locked shelves.
3. **2-3 Throne Hall:** arena waves with mixed enemies, then the boss.

**Boss: The Hollow Dragon.** The dragon they drew as the castle's final boss, now made of static.

- Phase 1: it breathes a static beam. Miko blocks it with her shield while Kai burns the glowing scales on its sides.
- Phase 2: it flies and summons minions. Miko charges minions into Kai's Flame Walls; Kai hits it with Meteor when it lands.
- Phase 3: it tries to split them up with a wall of static. Miko reflects Kai's fireballs through a gap in the wall to hit its heart.

**Memory 2: "The Hidden Room" (unlocked after the boss)**

- Behind the throne is a room Kai never knew existed: Miko built it secretly.
- Flashback, age 15: Miko alone at her computer at night, crying, typing a long goodbye message and hiding it in this room. She says to herself: "I'll show him at launch. He'll understand."
- The actual message is corrupted and can't be read yet.

**End-of-world scene:** Kai: "You were going to tell me?" Miko: "I *waited* for you. All day." Kai says nothing, but for the first time he walks next to her instead of ahead of her. Pip hovers between them, quietly, and doesn't make a joke.

## World 3: The Glitched Core (the unfinished final level)

The "secret final level" they never built, now The Glitch's home: here Kai's side comes out, the goodbye message is finally read, and the two finish the game together.

**Look:** half-built geometry, floating wireframes, grey untextured blocks, pieces of Pixel Plains and the castle mixed in, flickering static. Music is the World 1 and World 2 themes, broken and remixed. Third-person camera returns.

**Ability pair**

| Player | Tool | Use 1 | Use 2 |
| --- | --- | --- | --- |
| Kai | **Copy/Paste** | **Copy:** stores a copy of one object he aims at | **Paste:** places that copy where he aims, max 2 copies in the world |
| Miko | **Layer Shift** | **Shift:** toggles into the Code Layer, where hidden wires, platforms and weak points are visible and solid for her only | **Pull Out:** drags one object out of the Code Layer into the real world so Kai can see and copy it |

**How they combine:** Miko shifts, finds a hidden platform only she can see, and pulls it out; Kai copies it and pastes a bridge. Miko must describe or ping what she sees in the Code Layer, because Kai can't see it: this world is built around talking.

**Level sections**

1. **3-1 Missing Textures:** learn Copy/Paste and Layer Shift on simple gaps.
2. **3-2 The Wire Maze:** Miko navigates the Code Layer and guides Kai through a maze he can't see.
3. **3-3 Memory Lane:** a run through broken copies of the prologue, Pixel Plains and the castle, using all three ability sets as they swap automatically per area.

**Memory 3: "Launch Day" (unlocked midway, before the final boss)**

- Flashback, age 15: Kai sitting on his bed on launch day, refusing to go. The next morning he runs to Miko's house to apologize. The house is empty; the moving truck is gone.
- He goes home and deletes the project folder. The Glitch is born from that moment.
- Present: Miko sees this for the first time. "You came?" Kai: "You were already gone."
- The corrupted message from the castle unlocks. Both read Miko's goodbye together (keep it short and simple: she's scared, she's sorry, and "you're my best friend, Player One").

**Final boss: The Unfinished (The Glitch's true form)**

- Phase 1: a static giant that uses the Crusher King's attacks. Abilities switch to the World 1 kit.
- Phase 2: it becomes the Hollow Dragon. Camera goes top-down and they're Mage and Knight again.
- Phase 3: its true form. Damage does nothing. Pip, finally stable, explains: "It's not a monster. It's the level you never finished."
- Phase 4, the ending sequence: no combat. They build the final level together: Miko pulls pieces out of the Code Layer, Kai copies and pastes them into place, while The Glitch slowly stops attacking. The last step is a giant **SAVE** button that needs both players to ground-pound it at the same time.
- The Glitch turns into a finished, beautiful final level: a starry sky over the whole kingdom.

## Epilogue: Continue

The game ends with the two back in the real world and choosing, on their own, to talk again.

1. **In-game goodbye:** under the new starry sky, Pip thanks them and says the game is finally complete. Pip: "Same time tomorrow, Player One? Player Two?" Then fades.
2. **Cutscene, real world:** split view again, both in their rooms, back at their screens. The *Starfall Kingdom* file now says "100% COMPLETE".
3. Miko types "hey", deletes it, types it again, sends it. Kai's phone buzzes. He smiles and calls her.
4. The split view merges into one frame.
5. **Credits** roll as "*Starfall Kingdom*, by Kai & Miko", followed by the real credits for *Glitched Together*
6. **End screen:** the title card: **CONTINUE? YES**

**Post-credits (optional):** Pip reappears and waves from a new, unfinished zone: a hook for a future update.

## Coder notes

The game is one linear run; build the shared systems first, then one world at a time (castle first, then Pixel Plains, then the Glitched Core).

Each world follows the same pattern inside: enter cutscene, sections with checkpoints, boss, memory cutscene, end scene, load next world.

**Story triggers**

| Trigger | Where | What it does |
| --- | --- | --- |
| Intro\_Continue | Game start | Plays the "CONTINUE?" cutscene, spawns both at the title screen |
| Prologue\_Gate | End of prologue | Both on plates → Glitch chase cutscene → load World 1 |
| W1\_Enter | World 1 start | Grants Pause Beam (Kai) and Grapple Line (Miko) |
| W1\_BossDefeated | After Crusher King | Memory 1 cutscene → end scene → load World 2 |
| W2\_Enter | Castle gate | Transform cutscene, switch to top-down camera, load Mage and Knight kits |
| W2\_LevelUp | On XP threshold | Opens the 2-choice upgrade screen for that player |
| W2\_BossDefeated | After Hollow Dragon | Memory 2 (hidden room) → end scene → load World 3 |
| W3\_Enter | World 3 start | Third-person camera, grants Copy/Paste (Kai) and Layer Shift (Miko) |
| W3\_Memory3 | After section 3-2 | Memory 3 cutscene, then the goodbye message is read |
| Final\_PhaseN | Final boss | Swaps ability kits and camera per phase (World 1 kit, castle kit, World 3 kit) |
| Final\_Save | Phase 4 | Both ground-pound the SAVE button within 0.5 s → ending cutscene |
| Epilogue\_End | After credits | Marks the save as 100% complete |

**Systems checklist**

- [ ] 2-player party and reserved server (TeleportService)
- [ ] Role assignment (Kai = P1, Miko = P2), kept through the whole run
- [ ] Base movement: double jump, dash, ground pound
- [ ] Ability framework: one ModuleScript per ability, validated on the server, kits loaded per world
- [ ] Shared checkpoints and the revive system
- [ ] Two-player plates and gates
- [ ] Camera modes: third-person, side-on, top-down midpoint
- [ ] Cutscene system (camera paths + dialogue boxes) and Pip's hint dialogue
- [ ] Combat: health, enemies, XP orbs and upgrade choices (castle)
- [ ] Code Layer: objects visible only on Miko's client, collision per player via collision groups; Pull moves an object into the shared world on the server
- [ ] Boss state machines (3 bosses, phase-based)
- [ ] Save data (DataStore): current world, checkpoint
